## 项目简介

**python_exercise** 是一套 Python 基础编程练习题合集，包含 **70+** 个独立的 .py 脚本，覆盖 Python 编程的各个基础领域。每个文件都是一个独立的小练习，适合 Python 初学者进行日常训练。

## 快速使用

```bash
# 克隆仓库
git clone https://github.com/jianglai520/python_exercise.git
cd python_exercise

# 运行任意练习（无需安装额外依赖）
python 数字求和.py
python 九九乘法表.py
python 判断字符串长度.py

# 推荐学习顺序
# 基础 -> 字符串 -> 列表 -> 字典 -> 文件 -> OOP -> 算法
```

## 推荐练习顺序

```
第1周：基础篇
  数字求和 -> 平方根 -> 三角形面积 -> 圆的面积
  -> 摄氏温度转华氏温度 -> 交换变量 -> 随机数生成

  数字奇偶性 -> 质数判断 -> 闰年判断 -> 最大公约数

第3周：字符串与列表
  判断字符串长度 -> 字符串大小写转换 -> 翻转字符串
  -> list常用操作 -> 复制列表 -> 移除重复元素

第4周：字典与文件
  合并字典 -> 字典排序 -> 读取文件 -> 写入文件 -> 文件IO

第5周：面向对象
  创建一个类 -> 封装 -> 计算器类 -> 银行账户类 -> 银行系统

第6周：算法进阶
  二分查找 -> 线性查找 -> 约瑟夫游戏 -> 阿姆斯特朗数
```
