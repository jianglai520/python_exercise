## 项目简介

**python_exercise** 是一套 Python 基础编程练习题合集，包含 **70+** 个独立的 .py 脚本，按 **7 个类别**组织为目录结构。每个文件都是一个独立的小练习，适合 Python 初学者进行日常训练。

## 快速使用

```bash
# 克隆仓库
git clone https://github.com/jianglai520/python_exercise.git
cd python_exercise

# 运行任意练习（无需安装额外依赖）
python 01_基础语法与计算/数字求和.py
python 02_条件判断与算法/九九乘法表.py
python 03_字符串操作/判断字符串长度.py

# 或查看某个类别的所有练习
ls 04_列表操作/
```

## 推荐练习顺序

| 周次 | 类别 | 推荐练习 |

| 第1周 | 基础语法与计算 | 数字求和 -> 平方根 -> 三角形面积 -> 温度转换 -> 交换变量 |

| 第4周 | 列表操作 | list常用操作 -> 复制列表 -> 移除重复 -> 翻转列表 |

| 第6周 | 面向对象 + 综合 | 创建类 -> 封装 -> 计算器 -> 银行系统 -> 任务清单 |
